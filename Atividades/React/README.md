#  Jogo da Velha (Tic-Tac-Toe) em React

Um jogo da velha simples e moderno desenvolvido em ReactJS como projeto de aprendizado. O aplicativo conta com lógica de detecção de vitória, empate e reinício de partida, estilizado com um tema escuro (*dark mode*).

🔗 **[Acesse o projeto online na Vercel](https://react-seven-rho.vercel.app)**

---

## 🚀 Tecnologias Utilizadas

* **React.js** - Biblioteca para construção da interface
* **JavaScript (ES6+)** - Lógica do jogo
* **CSS3** - Estilização customizada e layout em Grid
* **Vercel** - Hospedagem e deploy contínuo
